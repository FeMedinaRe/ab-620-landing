Dominios del examen

Integración de sistemas empresariales
  • Priorizar conectores existentes de Power Platform y APIs REST sobre sistemas expuestos (SAP, Dynamics, ERPs).
  • Crear conectores personalizados solo cuando no exista alternativa; gobernarlos con soluciones y DLP.
  • Evaluar latencia, límites de tasa, autenticación y contratos de datos antes de conectar.
Estrategia de identidad
  • Microsoft Entra ID con autorización delegada (OAuth 2.0) para usuarios internos.
  • Identidades externas: B2B/B2C o proveedores federados.
  • Principio de mínimo privilegio: permisos de aplicación y de fila en Dataverse.
Canales y despliegue
  • Canales nativos: Microsoft Teams, web, Microsoft 365 Copilot, Azure Communication Services.
  • Publicación por ambiente: desarrollo → pruebas → producción mediante soluciones.
  • Power Platform Pipelines para promoción controlada y auditoría de cambios.
IA responsable, seguridad y gobernanza
  • Transparencia (avisar que es un bot), filtros de contenido y revisión humana en decisiones de alto impacto.
  • Políticas DLP por tenant: agrupar, permitir o bloquear conectores.
  • Auditoría, cumplimiento y guardrails contra prompt injection.
Componentes reutilizables y agent flows
  • Empaquetar temas, acciones y conectores en soluciones compartidas.
  • Agent flows (Power Automate) para procesos deterministas: acciones, integraciones, lógica de negocio.
  • Separación de responsabilidades: temas = conversación; flujos = ejecución.
Human-in-the-loop, acciones y manejo de errores
  • HITL para aprobaciones, acciones irreversibles y baja confianza del modelo.
  • Acciones con esquema tipado, autenticación y reutilización de conectores.
  • Errores: reintentos limitados, mensajes claros, escalamiento humano y telemetría.
Topics y adaptive cards
  • Topics definen el enrutamiento de conversación (triggers, condiciones, nodos).
  • Adaptive cards: tarjetas JSON interactivas (texto, imágenes, acciones) por canal.
  • Combinar cards con validación de entradas y acciones del agente.
Fuentes de conocimiento empresarial
  • Copilot connectors / knowledge sources: recuperación RAG sobre fuentes empresariales.
  • Power Platform / Dataverse: datos estructurados con permisos de fila y DLP.
  • Azure AI Search: búsqueda híbrida (vectorial + texto), filtrados y citas.
Herramientas (tools) del agente
  • Computer use: último recurso para apps legacy sin API (interacción visual con GUI).
  • MCP tools: estándar abierto para descubrir e invocar herramientas de forma homogénea.
  • Custom connectors: contratos tipados, autenticación, políticas y ALM.
  • REST APIs: acciones genéricas con manejo de errores y versionado.
Colaboración multi-agente
  • A2A protocol: descubrimiento (Agent Card), intercambio de tareas y agregación de resultados.
  • Foundry agents: agentes de Azure AI Foundry invocados como herramienta externa.
  • Fabric agents: análisis y acciones sobre activos de Fabric (Power BI, Lakehouse, notebooks).
Integración con Azure
  • Azure AI Search (RAG), Azure OpenAI (modelos y evaluaciones), Azure Functions (lógica serverless).
  • Azure Key Vault para secretos: rotación, RBAC y auditoría.
  • Application Insights: latencia, fallos de acciones, traces de conversación y SLO.
Métodos de evaluación
  • Evaluaciones automatizadas: ground truth, calidad de respuesta, seguridad/jailbreak.
  • Pruebas manuales de flujos críticos y pruebas de carga/latencia.
  • Iterar con telemetría real (Application Insights) para detectar brechas.
Test sets
  • Conjuntos curados de entradas con resultados esperados y criterios de puntuación.
  • Ejecutar en cada cambio para detectar regresiones de calidad.
  • Incluir casos negativos y de seguridad además de los casos felices.
ALM y Power Platform Pipelines
  • Empaquetar el agente en soluciones y promover entre ambientes con Pipelines.
  • Revisiones, aprobaciones y trazabilidad de despliegues.
  • Estrategia de rollback ante incidencias en producción.
Variables de entorno y soluciones
  • Externalizar URLs, IDs y flags por ambiente en environment variables.
  • Soluciones: versionado e integración de componentes del agente.
  • Separar configuración de lógica para despliegues seguros.
